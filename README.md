# Cambridge-United-Recruitment-Analysis
Repo for Cambridge United Recruitment Analysis project for the upcoming 2026 summer transfer window

---

## Why I Built This

Analysis to assess where Cambridge United could improve their squad or replace outgoing players this summer following their promotion to League One

---

## What It Does

Creates longlists for 4 positions (GK, CB, AM/LW/RW and ST) using my own position profiles that are adjusted for Cambridge United's playing style. The analysis uses normalised z-scores to create an overall rating for each player in these positions and generates a longlist of potential targets

---

## Inputs

Wyscout event data in CSV format

---

## Output

For each position:  
- Player ratings (longlist)
- Player z-scores for interogation if required
- Pizza plot for selected CUFC players in each position

---

## Libraries Used

- pandas, numpy, scipy - data manipulation and analysis.
- matplotlib, mplsoccer, PIL - visualisation.
